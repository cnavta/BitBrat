## Key Components to Migrate

### 1. McpBridge.translateTool() Execute Function
**Location**: `src/common/mcp/bridge.ts` lines 60-112

**Core Logic**:
```typescript
execute: async (args: any, context: any) => {
  const start = Date.now();
  let error = false;
  let responseSize = 0;

  try {
    // STEP 1: Call MCP tool (with or without proxy invoker)
    const result = this.invoker
      ? await this.invoker.invoke(this.serverName, mcpTool.name, args, this.client, context, this.invokerOptions)
      : await this.client.callTool({
          name: mcpTool.name,
          arguments: args,
          _meta: context ? {
            userRoles: context.userRoles,
            userId: context.userId,
            correlationId: context.correlationId,
            sessionId: context.sessionId,
          } : undefined
        } as any);

    // STEP 2: Check for errors in result
    if (result.isError) {
      error = true;
      throw new Error(`MCP Tool Error: ${JSON.stringify(result.content)}`);
    }

    // STEP 3: Extract text content from result
    const content = result.content as any[];
    const textParts = content
      .filter((c: any) => c.type === 'text')
      .map((c: any) => c.text);

    if (textParts.length > 0) {
      const response = textParts.join('\n').trim();
      if (response.length > 0) {
        responseSize = Buffer.byteLength(response, 'utf8');
        return response;
      }
    }

    // STEP 4: Fallback to full content if no text parts
    const fallback = result.content;
    responseSize = Buffer.byteLength(JSON.stringify(fallback), 'utf8');
    return fallback;

  } catch (e) {
    error = true;
    throw normalizeError(e);  // Unwrap nested MCP errors
  } finally {
    // STEP 5: Record stats (duration, error, response size)
    const duration = Date.now() - start;
    if (this.stats) {
      this.stats.recordCall(this.serverName, toolId, duration, error, responseSize);
    }
  }
}
```

**Dependencies**:
- `this.client` (MCP Client instance)
- `this.invoker` (ProxyInvoker - optional)
- `this.stats` (McpStatsCollector)
- `normalizeError()` utility (src/common/mcp/error-utils.ts)

### 2. Tool Invocation Handler (tool-gateway MCP server)
**Location**: `src/apps/tool-gateway.ts` lines 2399-2483

**Core Logic**:
```typescript
sessionServer.setRequestHandler('tools/call', async (request, ctx) => {
  // DEDUPLICATION: Prevent duplicate executions
  const toolName = request.params.name;
  const args = request.params.arguments || {};
  const argsHash = JSON.stringify(args);
  const dedupKey = `${toolName}:${argsHash}`;

  let executionPromise = this.inFlightRequests.get(dedupKey);
  if (executionPromise) {
    // Await existing execution
    return await executionPromise;
  }

  // TOOL LOOKUP
  const id = request.params.name;
  const tool = this.registry.getTool(id);
  if (!tool) throw new Error(`Tool not found: ${id}`);

  // RBAC VALIDATION
  const reqContext = this.getRequestContext(request, ctx, context);
  const allowed = this.rbac.isAllowedTool(tool, tool.originServer ? this.serverConfigs.get(tool.originServer) : undefined, reqContext);
  if (!allowed) throw new Error('Forbidden');

  // EXECUTION
  logger.trace('tool_gateway.mcp.call_tool.start', { id, args, reqContext });
  const start = Date.now();

  executionPromise = (async () => {
    try {
      // Call tool.execute() (which was created by McpBridge.translateTool)
      const result = await tool.execute?.(args as any, {
        sessionId,
        userRoles: reqContext.roles,
        userId: reqContext.userId,
        modelId: 'tool-gateway'
      });

      const duration = Date.now() - start;
      logger.trace('tool_gateway.mcp.call_tool.success', { id, duration });

      // RESULT TRANSFORMATION
      if (typeof result === 'string') {
        return { content: [{ type: 'text', text: result }] } as any;
      }
      return { content: [{ type: 'text', text: JSON.stringify(result) }] } as any;

    } catch (error: any) {
      const duration = Date.now() - start;
      const normalized = normalizeError(error);
      logger.error('tool_gateway.mcp.call_tool.error', { id, error: normalized.message, duration });
      throw error;
    } finally {
      // CLEANUP
      this.inFlightRequests.delete(dedupKey);
      this.completedRequests.set(dedupKey, Date.now());
    }
  })();

  this.inFlightRequests.set(dedupKey, executionPromise);

  try {
    return await executionPromise;
  } catch (error) {
    throw error;
  }
});
```

**Dependencies**:
- `this.registry` (ToolRegistry)
- `this.rbac` (RbacEvaluator)
- `this.inFlightRequests` (Map - deduplication)
- `this.completedRequests` (Map - deduplication)
- `normalizeError()` utility

## Execution Flow Analysis

### Current Flow (tool-gateway)
```
1. Tool registered via McpBridge.translateTool()
   └─ Creates execute() function attached to tool

2. llm-bot calls tool-gateway via MCP
   └─ tools/call handler invoked

3. tool-gateway handler:
   ├─ Deduplicates request
   ├─ Looks up tool in registry
   ├─ Validates RBAC
   └─ Calls tool.execute(args, context)

4. tool.execute() (from McpBridge):
   ├─ Calls this.client.callTool() to external MCP server
   ├─ Extracts text content from result
   ├─ Records stats
   └─ Returns result

5. tool-gateway handler:
   ├─ Transforms result to MCP format
   ├─ Logs success/error
   └─ Returns to llm-bot
```

### Proposed Flow (tool-orchestrator)
```
1. Tool registered in ToolRegistry (PostgreSQL)
   └─ Metadata stored, NO execute() function

2. llm-bot calls tool-orchestrator via MCP
   └─ Calls tool-orchestrator.execute(toolId, args, context)

3. tool-orchestrator ToolGateway.execute():
   ├─ Looks up tool in ToolRegistry (cache + PostgreSQL)
   ├─ Validates RBAC (User × Model) via validateToolAccess()
   ├─ Routes to executeMcpTool() if tool.source === 'mcp'
   └─ executeMcpTool() implementation:
       ├─ Gets MCP client for tool's origin server
       ├─ Creates AbortController for timeout
       ├─ Calls client.callTool() to external MCP server
       ├─ Extracts text content from result
       ├─ Logs event to Loki (NOT stats collector)
       └─ Returns result
```

## Key Differences: tool-gateway vs. tool-orchestrator

| Aspect | tool-gateway | tool-orchestrator |
|--------|--------------|-------------------|
| **Tool Storage** | In-memory ToolRegistry (Map) | PostgreSQL (ToolRegistry module) |
| **Execute Function** | Attached to each tool object | Centralized executeMcpTool() method |
| **Stats** | McpStatsCollector (in-memory) | Loki event logging (persistent) |
| **RBAC** | Agent-based (agentAllowlist) | Model-based (User × Model) |
| **Deduplication** | In-flight requests Map | NOT needed (tool-orchestrator doesn't expose MCP server) |
| **Timeout** | None (relies on MCP client) | AbortController (configurable per tool) |
| **Retry** | None (optional via ProxyInvoker) | Built-in exponential backoff |

```typescript
// 1. Get MCP client
const client = await this.mcpClientManager.getClient(tool.metadata.mcpServer);

// 2. Create timeout controller
const controller = new AbortController();
const timeout = setTimeout(() => controller.abort(), timeoutMs);

try {
  // 3. Call MCP tool
  const result = await client.callTool({
    name: tool.name,
    arguments: args,
    _meta: {
      userRoles: context.userRoles,
      userId: context.userId,
      correlationId: context.correlationId,
      sessionId: context.sessionId,
    }
  }, { signal: controller.signal });

  // 4. Check for errors
  if (result.isError) {
    throw new Error(`MCP Tool Error: ${JSON.stringify(result.content)}`);
  }

  // 5. Extract text content
  const content = result.content as any[];
  const textParts = content
    .filter((c: any) => c.type === 'text')
    .map((c: any) => c.text);

  const response = textParts.length > 0
    ? textParts.join('\n').trim()
    : JSON.stringify(result.content);

  // 6. Log to Loki
  await this.logToolInvocation({
    toolId: tool.id,
    modelId: context.modelId,
    status: 'success',
    durationMs: Date.now() - startTime,
    correlationId: context.correlationId,
  });

  return { isError: false, content: response };

} catch (err) {
  await this.logToolInvocation({
    toolId: tool.id,
    modelId: context.modelId,
    status: 'error',
    errorMessage: err.message,
    correlationId: context.correlationId,
  });
  throw normalizeError(err);
} finally {
  clearTimeout(timeout);
}
```
